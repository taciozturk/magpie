# magpie - ECS package project in Swift

magpie is a personal project where i try to implement a lightweight ECS package aimed as a backend for any game logic and renderer of your choice.

current implementations:
- World
- EntityAllocator
- ComponentStore
- CommandBuffer

outstanding implementations
- Query (for querying stores for components. will include with, without and anyof functionality based on the component type)
- System (for processing components)
- EventQueue (for event handling)
